# 🎮 Hangman Game Using Python

## 📌 About the Project

Hangman Game is a word-guessing game developed using Python.
Players guess a hidden word one letter at a time within a
limited number of incorrect guesses.

This project provides four different game modes, allowing
players to play with friends or interact with the computer.

## 🚀 Features

- Play with Friend
- Friend with Play
- Play with Computer
- Computer with Play
- Random word selection
- Hidden word display
- Letter-by-letter guessing
- Limited chances to guess the word
- Hangman drawing based on incorrect guesses
- Words categorized into Animals, Fruits and Food,
  Technology, Nature and Places, and General Words

## 🛠️ Technologies Used

- Python
- Random Module
- OS Module
- Functions
- Lists and Strings
- Conditional Statements
- Loops
- Modules and Imports

## ▶️ How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   python Main.py

6. Select a game mode and start playing.
